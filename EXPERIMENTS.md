# EXPERIMENTS.md

The five First Experiments from `07 — POC Roadmap` ("First Experiments"), to be run
after P0 and before any P1 work. P0 proves the mechanics; these test the product
hypothesis in `01 §1.1`. Record method, data, and results under each heading.

## 1. Claim identity

Import several real documents with similar but non-identical claims. Measure how often
candidate `SAME_AS` suggestions are wrong, and confirm no distinctions are lost.

_Not yet run._

## 2. Single-user value

Verify the citations and quotations in 5–10 real AI-generated documents with no
community contributions. Record time spent, errors caught, and whether the user would do
it again.

_Not yet run._

## 3. Audit multiplier

For several agent/model configurations: useful accepted contributions ÷ (audits +
corrections required). A configuration below 1 costs more than it helps.

_Not yet run._

## 4. Answers without graphs

Can users explain a claim's status from the answer card alone? Test with people who
never open the graph.

_Not yet run._

## 5. Independence impact

How often does grouping change a state (not just the number) in real material?

_Not yet run._
